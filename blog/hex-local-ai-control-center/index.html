Introducing H.E.X.: My Local AI Control Center for Hermes Agent

Nov 9, 2026

H.E.X. stands for Hermes Execution eXchange. I built it as a local control center for Hermes Agent: one dashboard where I chat with my agent profiles, stop a turn, talk to it by voice, manage scheduled jobs and route Telegram topics, all on my own machine.

← Blog

Audio overview · 23 min

Local chat, end to end

Chat runs end to end on local Ollama models (currently gemma4:12b). Models load when I tell them to from the dashboard, and services start when I start them. Nothing spins up in the background on its own.

What shipped in v0.5.0

H.E.X. is at v0.5.0, still pre-1.0, and five build phases are done:

  • Phase 1, chat. I type a message and it runs as a live Hermes chat turn on one of my agent profiles.
  • Phase 2, Stop. Every turn gets its own ID, so the Stop button ends that exact turn and leaves the services underneath it running.
  • Phase 3, voice. Push-to-talk voice with local speech-to-text and spoken replies through a local voice engine. Push-to-talk and transcription are tested and working.
  • Phase 4, schedule. One Schedule view lists jobs across all my profiles, and I can pause, resume or delete any of them from there.
  • Phase 5, Telegram routing. Telegram topics route to their own profiles: dev, research and assistant.

Part of the Hermes ecosystem

H.E.X. is the control center of my Hermes ecosystem. It sits alongside Hermes Sentinel, which is now in the official Hermes plugin catalog.
