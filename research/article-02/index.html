Mapping Agent Data Before a Historical Audit

Technical case study: read-only inventory, masked labeling, source locators, calibration, and the codex-map audit extension.

← Research

Design requirements

The implementation README records Justin Strange’s role:

“I'm Justin Strange, an independent systems designer. I spotted the problem, designed the safety rules (helpers only ever see masked text, the source stays untouched, and I freeze the labels before the full run), required that the skill be proven with before-and-after tests, and decided what counted as done.”

Pipeline architecture

  • Pass 1: inventory files, count them in two ways, scan secret patterns, extract masked examples, and create batches.
  • Pass 2: label masked batches through a local Ollama endpoint. Stop after the first two batches for label review, then continue with the frozen label set.
  • Pass 3: validate returns against their batch locators, merge the index, and check generated outputs for leaks.

Locators use file:line or SQLite table/row references. Unreadable records go to unread.jsonl with a reason. Full secret values are isolated in the local security-findings.jsonl file; the model receives masked batches.

Calibration

Calibration creates synthetic practice data, runs the deterministic mapping and merge/leak-check steps, and compares findings with a planted-secret manifest. A PASS requires zero missing findings, zero extra findings, and successful pipeline steps. Pass 2 labeling is optional for calibration.

python3 wrapper/cli.py calibrate

Audit extension

Phase 4 specifies provenance from conversation exports, agent logs, Git pickaxe/blame, fingerprint search, and month-by-month occurrence counts. Its current roadmap places specification before implementation and validation. The mapping pipeline supplies the inventory, masking, locators, calibration, and output structure for that extension.

Scope

Secret detection covers recognized patterns and seeded values; its summary explicitly records partial coverage. The local test run uses synthetic fixtures. It does not measure historical inferred-intent drift in private conversations or establish production labeling throughput.
