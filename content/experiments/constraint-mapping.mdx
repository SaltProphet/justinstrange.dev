## Hypothesis

A constraint map may be more useful than a feature map when the work is still being shaped.

## Setup

Start with one change request and record every constraint that affects its path: technical coupling, ownership, timing, confidence, and reversibility.

## Observation

The map is already exposing where language is doing too much work. The next iteration will separate facts from assumptions instead of using one visual grammar for both.
