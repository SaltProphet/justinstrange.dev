Lead Qualification & Outreach Approval Workflow

Qualify leads, review drafted messages, approve execution, and track delivery outcomes in one stateful workflow.

← Work

Browser-based reference implementation

Use case

An outreach workflow needs to track qualification, drafts, review decisions, delivery outcomes, and recipient suppression.

How it works

A stateful pipeline with deterministic qualification, AI-provider and delivery adapters, operator approval, separate execution controls, and an event history.

Inspect the implementation

The repository documents the operator walkthrough and behavioral tests for approval, duplicate protection, suppression, delivery outcomes, and quotas.

Scope

The reference uses fictional leads, deterministic mock providers, and browser-local state.
