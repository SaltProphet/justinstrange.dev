Local Multi-Voice Audio Production

Generate voices, record audio, arrange dialogue, and export WAV files from a local production workspace.

← Work

Local Windows application

Use case

Working with generated voices involves references, dialogue, recordings, editing, and export across a single production session.

How it works

A locally hosted voice workspace with speech generation, voice references, recording, non-destructive cleanup, a multitrack timeline, and WAV export.

Inspect the implementation

The repository contains the application, Windows setup scripts, user documentation, and a self-narrated video demonstration. The image is the demonstration poster.

Scope

GPU inference runs on the host PC. The demonstration previews a local development build; its transcription and voice-design controls are ahead of the published source.

Source & documentation

  • Source repository
  • Documentation

Production workflow

Windows setup creates an isolated Python environment, installs the pinned Qwen3-TTS source and model weights, builds the frontend, and installs demo audio. The local host binds to 127.0.0.1:8765. GPU inference and session files remain on the host PC.

The repository’s self-narrated demo follows voice generation, dialogue sequencing, editing, arrangement, and WAV export. Generation waits are fast-forwarded; its transcription and voice-design controls preview a development build.

Review procedure

Follow voice-studio/README.md and voice-studio/AURAVOICE.md for setup and the verification record.
