# Justin Strange — portfolio static export

Recovered from the publicly rendered ChatGPT Sites website. Contains 13 static HTML pages and website assets. Original editable Next.js source is not included.

Deploy on Vercel as **Other** framework, root directory `/`, with no build command and output directory `.`. The site uses absolute root paths; serve it from the domain root.

The Next.js hydration scripts were removed to avoid relying on the original Sites application runtime. The independent theme script is retained. Test navigation, media, theme, and responsive layouts after deployment.
